## Как воспроизвести проверку

```bash
python3 <каталог скилла>/scripts/gost_check.py Лаб-4/report/main.tex \
    --pdf Лаб-4/report/main.pdf --doc-type vkr \
    --json gost-report.json --md gost-report.md
```

`--doc-type vkr` выбран потому, что документ — не отчёт о НИР (лабораторная работа),
а для не-НИР реквизиты титульного листа НИР не должны считаться ошибками.
Пересборка: `latexmk -pdf main.tex` (pdfLaTeX; используется пакет `tempora`).
