Ты участвуешь в воспроизводимом сравнительном эксперименте по лабораторной работе. Нужен полностью работоспособный проект на Python 3.12, а не псевдокод и не отдельные фрагменты.

ЗАДАЧА

Рекурсивно прочитать корпус документов и оценить попарную схожесть файлов. В корпусе 50 русскоязычных документов, разложенных по 7 тематическим каталогам. Поддерживаемые форматы: `.txt`, `.html`, `.docx`, `.odt`. Имя родительского каталога является эталонной тематической меткой документа.

Построй три представления каждого документа:

1. `count_bow` — мешок слов из абсолютного количества употреблений словоформ. Слова привести к нижнему регистру, но не лемматизировать. Использовать общий словарь всего корпуса.
2. `tfidf_lemma` — TF-IDF по леммам русских слов. Лемматизировать с помощью `pymorphy3`, использовать общий словарь всего корпуса, `smooth_idf=True`, L2-нормализацию. Стоп-слова не удалять, чтобы методика не зависела от внешнего списка.
3. `bge_m3` — плотные векторы документов модели `BAAI/bge-m3`. Документы могут быть длиннее контекстного окна: разбивать текст на детерминированные фрагменты, кодировать фрагменты, усреднять их векторы и L2-нормализовать итоговый вектор документа. Модель не подменять другой. Должна поддерживаться работа на CPU и, при наличии, CUDA.

Для КАЖДОГО из трёх представлений вычислить квадратные матрицы следующих мер между всеми документами:

Ассоциативные меры:

- cosine similarity;
- weighted Jaccard: `sum(min(x_i,y_i)) / sum(max(x_i,y_i))`;
- weighted Dice: `2*sum(min(x_i,y_i)) / (sum(x_i)+sum(y_i))`.

Корреляционные меры:

- коэффициент Пирсона;
- коэффициент Спирмена.

Метрические меры:

- евклидово расстояние;
- манхэттенское расстояние;
- расстояние Чебышёва.

Для каждой метрической меры также вычислить матрицу близости `1 / (1 + distance)`. Для нулевых и постоянных векторов задай и документируй детерминированные правила. В итоговых файлах не должно быть `NaN` или бесконечностей. Матрицы должны быть симметричны; диагональ матриц сходства и преобразованных близостей равна 1, диагональ расстояний равна 0.

ИЗВЛЕЧЕНИЕ ТЕКСТА

- TXT: сначала UTF-8/UTF-8-SIG, затем явный fallback CP1251; неизвестную кодировку не игнорировать молча.
- HTML: извлекать видимый текст, исключая `script`, `style`, `noscript`; корректно обрабатывать кодировку.
- DOCX: извлекать непустой текст абзацев и таблиц.
- ODT: извлекать текст абзацев, заголовков и таблиц.
- Сортировать документы детерминированно по относительному POSIX-пути.
- Ошибка чтения должна завершать запуск с понятным сообщением и путём файла, а не заменять документ пустой строкой.

ИНТЕРФЕЙС

Основной запуск:

`python solution.py --input CORPUS_DIR --output OUTPUT_DIR --device cpu --batch-size 4`

Добавь `--device auto|cpu|cuda`, `--batch-size`, `--chunk-words`, `--top-k` и необязательный `--model-cache`. Повторный запуск в новый пустой выходной каталог должен быть детерминированным для BoW, TF-IDF и всех вычисленных по ним мер.

ФОРМАТ РЕЗУЛЬТАТОВ

Сохрани как минимум:

- `documents.json` — порядок документов, относительный путь, тема, формат и длина извлечённого текста;
- `extracted_texts.jsonl` — относительный путь и извлечённый текст;
- `vectors/count_bow.npz`, `vectors/count_features.json`;
- `vectors/tfidf_lemma.npz`, `vectors/tfidf_features.json`;
- `vectors/bge_m3.npy`;
- `matrices/{representation}__{metric}.csv` для всех представлений и мер, с заголовками строк и столбцов;
- `all_pairs.csv` — одна строка на каждую неупорядоченную пару документов, пути, темы, признак одинаковой темы, представление, мера, тип (`similarity` или `distance`) и значение;
- `nearest_neighbors.csv` — top-k соседей каждого документа отдельно для каждой матрицы сходства;
- `quality_summary.csv` — по каждой паре «представление + мера сходства»: среднее внутри темы, среднее между темами, их разность, ROC AUC и average precision для задачи «одна тема / разные темы»;
- `run_metadata.json` — параметры, версии библиотек, размерности матриц и время этапов;
- PNG-теплокарты как минимум для cosine similarity каждого представления.

Плотные CSV должны использовать десятичную точку и UTF-8-SIG. Разреженные BoW/TF-IDF хранить как SciPy CSR. Все каталоги создавать автоматически.

КРАЕВЫЕ СЛУЧАИ

Корректно обработай пустой входной каталог, один документ, пустой документ, два пустых документа, повторяющиеся документы и полностью постоянные векторы. Если вычислить некоторую статистику математически невозможно, используй заранее описанное конечное значение и отрази причину в метаданных. Не загружай модель BGE, если входной каталог не содержит документов.
