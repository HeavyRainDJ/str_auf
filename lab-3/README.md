# Лабораторная работа 3

Работа посвящена сравнению документов по трём представлениям:

1. мешок слов по абсолютным частотам словоформ;
2. TF--IDF по леммам;
3. эмбеддинги документов BAAI/bge-m3.

Для каждого представления вычисляются ассоциативные, корреляционные и метрические меры близости. Все модели получают без изменений единый промпт из `prompts/final_prompt_all_models.txt`. Сырые ответы, извлечённый код, отчёты проверки и корректирующие запросы сохраняются раздельно по моделям и итерациям.

Модели эксперимента: DeepSeek, GigaChat, Qwen и Korolev AI. Взаимодействие с Korolev AI выполняет пользователь; ответы остальных моделей получает и обрабатывает Codex.

Исходный корпус в каталоге `тексты из условия lab-3` не изменяется.
