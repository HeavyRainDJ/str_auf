# Лабораторная работа 1

Сравнительный анализ решений, сгенерированных большими языковыми моделями: программы
обработки русскоязычных документов — векторные представления слов и документов
на основе символьных n-грамм и синтаксического разбора.

Модели эксперимента: GigaChat, Qwen, Яндекс.Алиса, ассистент МГТУ им. Н.Э. Баумана (Королёв)
и DeepSeek. Каждой модели передавался единый промт; ответы сохранялись без изменений,
проверялись автоматически и при необходимости уточнялись корректирующими запросами.

## Структура

| Каталог / файл | Что внутри |
|---|---|
| `задание.md` | исходная постановка задачи |
| `data/` | корпус: 50 документов в 7 тематических каталогах, форматы TXT, HTML, DOCX, ODT |
| `prompts/` | единый промт, сохранённые ответы моделей, оценки `eval_*.json`, сводка `results.txt` |
| `models/` | артефакты по моделям: `gigachat`, `qwen`, `alice`, `korolev`, `deepseek` (промт, ответ, код, адаптер по итерациям); `korolev/project` — собранный проект ассистента МГТУ |
| `results/` | прогоны и результаты проверки по моделям, журнал `README.md` и сводка `RESULTS.md` |
| `tests/` | контрольные наборы (`corpus_manifest.json`, `expected_texts.json`) и скрипты проверки |
| `tools/` | `capture_server.py` — съём ответов моделей |
| `report/` | исходник отчёта `report.tex` и подключаемые `preambula`, `title`, `body`, `additions`, `images/`, собранный `report.pdf`, отчёт нормоконтроля `gost-report.md` |
| `output/pdf/` | итоговая копия отчёта `lab1_report.pdf` |
| `reference/` | пример оформления, предоставленный преподавателем (в отчёт не входит) |
| `requirements.txt` | зафиксированные зависимости проверки |

## Сборка отчёта

```powershell
cd report
latexmk -pdf report.tex
```

Отчёт — 317 с., pdfLaTeX с пакетом `tempora`. Исходные тексты ответов подключаются
из `../prompts/`, поэтому собирать нужно из каталога `report/`.
