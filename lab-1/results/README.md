# Лабораторная работа 1: журнал выполнения

Исходные материалы и пример не изменяются. Ответы моделей сохраняются отдельно от тестового стенда. Исправления модельного кода запрашиваются у соответствующей модели и фиксируются новой итерацией.

План: единый промпт -> исходный ответ -> извлечение кода без ручного исправления -> статическая проверка -> запуск на контрольных примерах и 50 исходных документах -> обратная связь модели -> повторная проверка -> сравнительный отчёт.

Ассистент МГТУ: ответы предоставляет пользователь. DeepSeek: при предыдущей проверке требовалась авторизация. Эти результаты не подменяются ответами других моделей.
