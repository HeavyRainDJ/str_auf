\chapter{Технологическая часть}

\section{Выбор языка и среды программирования}

Для реализации программного обеспечения и взаимодействия с большими языковыми моделями были использованы следующие средства:
\begin{itemize}
    \item браузер Safari (для взаимодействия с веб-интерфейсами облачных моделей Gemini и YandexGPT)~\cite{safari};
    \item программный комплекс LM Studio (для локального развёртывания и инференса модели Qwen 3 Coder)~\cite{lm_studio};
    \item язык программирования Python (версия 3.12)~\cite{python_3_12}.
\end{itemize}

Для работы с PDF-файлами и текстовыми данными использовались следующие стандартные и внешние библиотеки Python:
\begin{itemize}
    \item \texttt{re} (работа с регулярными выражениями)~\cite{python_re};
    \item \texttt{os} (взаимодействие с файловой системой)~\cite{python_os};
    \item \texttt{sys} (обработка системных параметров и потоков ввода-вывода)~\cite{python_sys};
    \item \texttt{typing} (аннотация типов данных)~\cite{python_typing};
    \item \texttt{PyPDF2} (извлечение текста из документов формата PDF)~\cite{pypdf2_docs}.
\end{itemize}

\section{Реализация программного обеспечения}

В данном разделе описаны итоговые решения, полученные в результате взаимодействия с каждой из исследуемых моделей. Код приводится в том виде, в котором он был принят как <<финальный>> после всех итераций исправлений. Полные листинги скриптов вынесены в соответствующие приложения.

\subsection{Решение, полученное от Gemini 3 Pro Preview}
Модель Gemini 3 Pro предложила решение с использованием оптимизированных регулярных выражений и строгой типизации. Итоговый код скрипта представлен в приложении~\ref{app:gemini_code}.

\subsection{Решение, полученное от Qwen 3 Coder}
Локальная модель Qwen 3 Coder предложила альтернативный вариант реализации. Полный листинг данного решения приведён в приложении~\ref{app:qwen_code}.

\subsection{Решение, полученное от YandexGPT 5.1 Pro}
Модель YandexGPT потребовала серию итеративных правок для достижения работоспособного результата. Финальная версия скрипта находится в приложении~\ref{app:yagpt_code}.

\section{Протоколы взаимодействия с БЯМ}

В данном разделе описан процесс взаимодействия с моделями. Полные логи переписки (промпты и ответы), демонстрирующие процесс выявления ошибок и уточнения требований, вынесены в приложения.

\subsection{Протокол диалога с Gemini 3 Pro}
Взаимодействие осуществлялось в режиме углублённых рассуждений (Thinking High). Полный протокол диалога приведён в приложении~\ref{app:gemini_log}.

\subsection{Протокол диалога с Qwen 3 Coder}
Взаимодействие с локальной моделью проходило через интерфейс LM Studio. Лог переписки представлен в приложении~\ref{app:qwen_log}.

\subsection{Протокол диалога с YandexGPT 5.1 Pro}
В ходе взаимодействия в режиме рассуждений (Think mode) были выявлены проблемы с контекстным менеджером файлов. Полный протокол приведён в приложении~\ref{app:yagpt_log}.
