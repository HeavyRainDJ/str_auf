Вот реализация программы на Python для проверки отсутствия неразрывного пробела в специальных сочетаниях слов и чисел:

```python
import PyPDF2
import re
from typing import Tuple, List

def check_non_breaking_space(file_path: str) -> Tuple[bool, List[Tuple[str, int, int]]]:
    """
    Проверяет отсутствие неразрывного пробела в специальных сочетаниях слов и чисел
    
    Args:
        file_path (str): Путь к PDF-файлу
        
    Returns:
        Tuple[bool, List[Tuple[str, int, int]]]: 
        - bool: True если нет нарушений, False если есть
        - List[Tuple[str, int, int]]: список найденных нарушений (строка, номер страницы, номер строки)
    """
    
    # Регулярное выражение для поиска специальных сочетаний без неразрывного пробела
    # Сочетания: "рисунок 1", "таблица 2", "от 1 до 5", "менее 5", "свыше 25"
    pattern = r'(?:рисунок|таблица|от|менее|свыше)\s+\d+(?:\s+до\s+\d+)?'
    
    # Регулярное выражение для поиска сочетаний с неразрывным пробелом (нужно для проверки)
    pattern_with_nbsp = r'(?:рисунок|таблица|от|менее|свыше)[\u00A0\u2000-\u200A\u202F\u205F\u3000]\d+(?:[\u00A0\u2000-\u200A\u202F\u205F\u3000]до[\u00A0\u2000-\u200A\u202F\u205F\u3000]\d+)?'
    
    # Список для хранения найденных нарушений
    violations = []
    
    try:
        # Открываем PDF файл
        with open(file_path, 'rb') as file:
            pdf_reader = PyPDF2.PdfReader(file)
            
            # Проходим по каждой странице
            for page_num, page in enumerate(pdf_reader.pages, 1):
                # Извлекаем текст с страницы
                text = page.extract_text()
                
                # Разбиваем текст на строки
                lines = text.split('\n')
                
                # Проверяем каждую строку
                for line_num, line in enumerate(lines, 1):
                    # Ищем все совпадения с шаблоном
                    matches = re.finditer(pattern, line)
                    
                    # Проверяем, есть ли неразрывный пробел в найденных совпадениях
                    for match in matches:
                        matched_text = match.group()
                        
                        # Проверяем, содержит ли найденная строка неразрывный пробел
                        if re.search(r'[\u00A0\u2000-\u200A\u202F\u205F\u3000]', matched_text):
                            violations.append((matched_text, page_num, line_num))
                
    except Exception as e:
        print(f"Ошибка при обработке файла: {e}")
        return False, []
    
    # Возвращаем результат: True если нет нарушений, False если есть
    return len(violations) == 0, violations

def main():
    """
    Основная функция для запуска программы
    """
    # Запрашиваем путь к PDF файлу у пользователя
    file_path = input("Введите путь к PDF-файлу: ").strip()
    
    if not file_path:
        print("Путь к файлу не указан")
        return
    
    try:
        # Вызываем функцию проверки
        is_valid, violations = check_non_breaking_space(file_path)
        
        # Выводим результат
        if is_valid:
            print("✓ Проверка пройдена: Неразрывные пробелы отсутствуют в специальных сочетаниях")
        else:
            print("✗ Найдены нарушения:")
            print("Нарушения найдены в следующих местах:")
            for violation in violations:
                text, page, line = violation
                print(f"  Строка: '{text}'")
                print(f"  Страница: {page}, Строка: {line}")
                print()
                
    except Exception as e:
        print(f"Ошибка выполнения программы: {e}")

if __name__ == "__main__":
    main()
```

### Описание реализации:

1. **Регулярные выражения:**
   - `pattern = r'(?:рисунок|таблица|от|менее|свыше)\s+\d+(?:\s+до\s+\d+)?'` - ищет специальные сочетания
   - `pattern_with_nbsp = r'(?:рисунок|таблица|от|менее|свыше)[\u00A0\u2000-\u200A\u202F\u205F\u3000]\d+(?:[\u00A0\u2000-\u200A\u202F\u205F\u3000]до[\u00A0\u2000-\u200A\u202F\u205F\u3000]\d+)?'` - ищет сочетания с неразрывным пробелом

2. **Функция `check_non_breaking_space`:**
   - Извлекает текст из PDF-файла с помощью PyPDF2
   - Разбивает текст на строки
   - Ищет специальные сочетания с помощью регулярных выражений
   - Проверяет наличие неразрывных пробелов (коды Unicode: \u00A0, \u2000-\u200A, \u202F, \u205F, \u3000)
   - Возвращает кортеж с результатом и списком нарушений

3. **Основная функция `main()`:**
   - Принимает путь к PDF-файлу от пользователя
   - Вызывает функцию проверки
   - Выводит результаты в удобочитаемом виде

### Особенности реализации:

- Обрабатывает ошибки чтения файла
- Поддерживает комбинации: "рисунок 1", "таблица 2", "от 1 до 5", "менее 5", "свыше 25"
