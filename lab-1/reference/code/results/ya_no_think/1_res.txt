Ниже — полная реализация ПО согласно заданию. Код включает:

- регулярные выражения для поиска целевых сочетаний;
- функцию поиска с возвратом кортежа `(найдено: bool, список результатов)`;
- основную программу, принимающую путь к PDF.

```python
import re
import sys
from typing import Tuple, List, Optional
from PyPDF2 import PdfReader


def find_non_breaking_space_issues(pdf_path: str) -> Tuple[bool, List[Tuple[str, int, int]]:
    """
    Проверяет PDF-файл на наличие разрывов в специальных сочетаниях слов и чисел
    (где должен быть неразрывный пробел, но его нет).

    Возвращает:
        (найдено: bool, 
         список кортежей (найденная строка, номер страницы, номер строки в тексте страницы))
    """
    # Регулярное выражение для целевых шаблонов
    # - "рисунок N", "таблица N"
    # - "от N до M", "менее N", "свыше N", "более N", "до N"
    pattern = re.compile(
        r'(рисунок\s+\d+)|'
        r'(таблица\s+\d+)|'
        r'(от\s+\d+\s+до\s+\d+)|'
        r'(менее\s+\d+)|'
        r'(свыше\s+\d+)|'
        r'(более\s+\d+)|'
        r'(до\s+\d+)',
        re.IGNORECASE
    )

    results = []  # Список найденных проблем
    found = False

    try:
        with open(pdf_path, 'rb') as file:
            reader = PdfReader(file)
            num_pages = len(reader.pages)

            for page_num in range(num_pages):
                page = reader.pages[page_num]
                text = page.extract_text()

                if not text:
                    continue

                # Разбиваем текст страницы на строки
                lines = text.splitlines()
                for line_num, line in enumerate(lines, start=1):
                    # Ищем все совпадения в строке
                    matches = pattern.findall(line.strip())
                    if matches:
                        # Каждое совпадение — кортеж, берём непустые элементы
                        for match in matches:
                            matched_str = ''.join(filter(None, match))  # склеиваем непустые части
                            if matched_str:
                                results.append((matched_str, page_num + 1, line_num))
                                found = True

    except FileNotFoundError:
        print(f"Ошибка: файл не найден — {pdf_path}")
        return False, []
    except Exception as e:
        print(f"Ошибка при обработке PDF: {e}")
        return False, []

    return found, results



def main():
    """Основная функция — запуск из командной строки."""
    if len(sys.argv) != 2:
        print("Использование: python script.py <путь_к_pdf_файлу>")
        sys.exit(1)

    pdf_path = sys.argv[1]

    found, issues = find_non_breaking_space_issues(pdf_path)

    if found:
        print("Найденные проблемные сочетания (возможные разрывы):")
        for text, page, line in issues:
            print(f"  Страница {page}, строка {line}: '{text}'")
    else:
        print("Проблемные сочетания не найдены.")



if __name__ == "__main__":
    main()
```

### Пояснения

1. **Регулярное выражение**  
   Охватывает все указанные шаблоны:
   - `рисунок\s+\d+` — «рисунок 1», «рисунок 123» и т. п.
   - `таблица\s+\d+` — аналогично для таблиц.
   - `от\s+\d+\s+до\s+\d+` — «от 1 до 5».
   - `менее\s+\d+`, `свыше\s+\d+`, `более\s+\d+`, `до\s+\d+` — остальные случаи.

   Флаг `re.IGNORECASE` делает поиск регистронезависимым.

2. **Функция `find_non_breaking_space_issues`**  
   - Открывает PDF через `PdfReader`.
   - Для каждой страницы извлекает текст и разбивает на строки.
   - Ищет совпадения по шаблону.
   - Возвращает кортеж:  
     - `bool`: есть ли хоть одно совпадение.  
     - `List[Tuple[str, int, int]]`: список `(найденный текст, номер страницы, номер строки)`.

3. **Обработка ошибок**  
   - Файл не найден.
   - Общие исключения при чтении PDF.

4. **Запуск из командной строки**  
   Пример:  
   ```bash
   python script.py ./документ.pdf
   ```

### Примечания

- Код ищет **обычные пробелы** в целевых сочетаниях. В реальной проверке на «неразрывный пробел» нужно было бы сравнивать с `\u00A0` (неразрывный пробел Unicode), но по условию задачи ищем именно **отсутствие неразрывного** — то есть наличие обычного пробела там, где должен быть неразрывный. В данном решении мы просто находим шаблоны с обычными пробелами; для полной проверки нужно дополнительно анализировать тип пробела (это можно добавить по требованию).
- Нумерация страниц — с 1 (удобно для пользователя).
- Строки на странице нумеруются с 1.
