Ниже приведён полный код на Python, решающий поставленную задачу.

```python
import re
import PyPDF2
from typing import Tuple, List, Tuple


def create_patterns() -> List[re.Pattern]:
    """
    Создаёт список регулярных выражений для поиска специальных сочетаний слов и чисел,
    где должен использоваться неразрывный пробел.
    """
    patterns = [
        # «рисунок N» (N — число)
        re.compile(r'рисунок\s+\d+', re.IGNORECASE),
        # «таблица N»
        re.compile(r'таблица\s+\d+', re.IGNORECASE),
        # «от N до M»
        re.compile(r'от\s+\d+\s+до\s+\d+', re.IGNORECASE),
        # «менее N»
        re.compile(r'менее\s+\d+', re.IGNORECASE),
        # «свыше N»
        re.compile(r'свыше\s+\d+', re.IGNORECASE),
    ]
    return patterns



def find_non_breaking_space_issues(pdf_path: str) -> Tuple[bool, List[Tuple[str, Tuple[int, int]]]:
    """
    Функция для поиска в PDF-файле случаев, где в специальных сочетаниях
    слов и чисел может отсутствовать неразрывный пробел.

    Args:
        pdf_path (str): путь к PDF-файлу

    Returns:
        Tuple[bool, List[Tuple[str, Tuple[int, int]]]]:
            - bool: True, если все найденные сочетания корректны (нет проблем),
                     False, если найдены потенциальные проблемы
            - List[Tuple[str, Tuple[int, int]]]: список найденных проблемных сочетаний
              с указанием текста и координат (страница, номер строки)
    """
    patterns = create_patterns()
    issues = []  # Список найденных проблем

    try:
        with open(pdf_path, 'rb') as file:
            reader = PyPDF2.PdfReader(file)
            total_pages = len(reader.pages)

            for page_num in range(total_pages):
                page = reader.pages[page_num]
                text = page.extract_text()

                if not text:
                    continue

                # Разбиваем текст на строки
                lines = text.splitlines()

                for line_num, line in enumerate(lines, start=1):
                    # Проверяем каждую строку на соответствие шаблонам
                    for pattern in patterns:
                        matches = pattern.finditer(line)
                        for match in matches:
                            matched_text = match.group()
                            # Проверяем, есть ли в найденном фрагменте неразрывный пробел (\u00A0)
                            if '\u00A0' not in matched_text:
                                issues.append((
                                    matched_text,
                                    (page_num + 1, line_num)  # страница и номер строки
                                ))

    except Exception as e:
        print(f"Ошибка при обработке PDF-файла: {e}")
        return False, []

    # Если issues пуст — проблем нет
    all_ok = len(issues) == 0
    return all_ok, issues



def main():
    """
    Основная функция программы.
    Запрашивает у пользователя путь к PDF-файлу и выводит результаты проверки.
    """
    pdf_path = input("Введите путь к PDF-файлу: ").strip()

    is_correct, issues = find_non_breaking_space_issues(pdf_path)

    if is_correct:
        print("\n✅ Все специальные сочетания содержат неразрывный пробел или не обнаружены.")
    else:
        print(f"\n❌ Найдено {len(issues)} потенциальных проблем с неразрывным пробелом:")
        for text, (page, line) in issues:
            print(f"  - '{text}' (страница {page}, строка {line})")



if __name__ == "__main__":
    main()
```

### Описание работы кода

1. **`create_patterns()`**  
   Создаёт список регулярных выражений для поиска целевых сочетаний:
   - «рисунок N»
   - «таблица N»
   - «от N до M»
   - «менее N»
   - «свыше N»

   Все шаблоны учитывают возможные пробелы (`\s+`) и регистронезависимость (`re.IGNORECASE`).

2. **`find_non_breaking_space_issues(pdf_path)`**  
   Основная функция, которая:
   - Открывает PDF-файл через `PyPDF2`.
   - Проходит по каждой странице.
   - Извлекает текст и разбивает его на строки.
   - Для каждой строки ищет совпадения по шаблонам.
   - Проверяет, есть ли в найденном фрагменте **неразрывный пробел** (`\u00A0`).
   - Если неразрывного пробела нет — добавляет в список проблем.
   - Возвращает:
     - `True`, если проблем нет, `False` — если есть.
     - Список кортежей `(найденный_текст, (номер_страницы, номер_строки))`.

3. **`main()`**  
   - Запрашивает у пользователя путь к PDF.
   - Вызывает основную функцию.
   - Выводит результат: либо подтверждение корректности, либо список проблем с указанием места.

### Примечания

- Неразрывный пробел в Unicode — `\u00A0`. В обычных текстах его часто заменяют на обычный пробел, что и является проблемой.
- Код обрабатывает только текстовый слой PDF. Если PDF сканированный (без текста), результат будет пустым.
- Нумерация страниц начинается с 1 (удобно для пользователя).
