### Основные моменты реализации:

1.  **Библиотека `PyPDF2`**: Она используется для чтения PDF. Важно отметить, что `PyPDF2` не всегда идеально сохраняет структуру строк (line breaks), поэтому координаты (номер строки) будут приблизительными, основанными на том, как текст извлекается постранично.
2.  **Регулярное выражение**: Вариант требует найти места, где **отсутствует** неразрывный пробел (NBSP, код `\u00A0`) в специальных сочетаниях, то есть там, где стоит обычный пробел.
    *   Примеры: "рисунок 1", "таблица 2", "от 1", "до 5", "менее 5", "свыше 25".
    *   Регулярное выражение ищет обычный пробел (` `) между ключевым словом и числом.
3.  **Логика поиска**: Мы ищем "ошибочные" ситуации (обычные пробелы), чтобы пользователь мог их исправить.

```python
import re
import PyPDF2
import os

def get_regex_pattern():
    """
    Задача 1: Разработать регулярные выражения для решения задачи по варианту.
    
    Вариант: Проверка отсутствия неразрывного пробела в специальных сочетаниях слов и чисел.
    Мы ищем ОБЫЧНЫЕ пробелы там, где должны быть неразрывные.
    
    Паттерны включают:
    - Слова "рисунок", "рис.", "таблица", "табл." + пробел + число
    - Предлоги/наречия "от", "до", "менее", "более", "свыше" + пробел + число
    
    (?i) - флаг игнорирования регистра (чтобы ловить "Рисунок" и "рисунок")
    \b - граница слова (чтобы не ловить "подрисовок")
    \d+ - одно или более число
    """
    patterns = [
        r"(?i)\b(рисунок|рис\.) \d+",
        r"(?i)\b(таблица|табл\.) \d+",
        r"(?i)\b(от) \d+",
        r"(?i)\b(до) \d+",
        r"(?i)\b(менее) \d+",
        r"(?i)\b(более) \d+",
        r"(?i)\b(свыше) \d+"
    ]
    # Объединяем все паттерны через ИЛИ (|)
    full_pattern = "|".join(patterns)
    return re.compile(full_pattern)

def check_pdf_spaces(pdf_path):
    """
    Задача 2: Реализовать функцию для поиска подстроки по варианту.
    
    Возвращает кортеж:
    (
      bool: Истина, если найдены "плохие" пробелы (обычные вместо неразрывных),
      list: Список кортежей [(найденная_строка, (номер_страницы, номер_строки_на_странице))]
    )
    """
    if not os.path.exists(pdf_path):
        print(f"Ошибка: Файл {pdf_path} не найден.")
        return False, []

    regex = get_regex_pattern()
    matches_found = []
    
    try:
        with open(pdf_path, 'rb') as file:
            reader = PyPDF2.PdfReader(file)
            
            # Перебираем страницы (нумерация с 1 для удобства пользователя)
            for page_num, page in enumerate(reader.pages, start=1):
                text = page.extract_text()
                
                if not text:
                    continue
                
                # Разбиваем текст страницы на строки
                lines = text.split('\n')
                
                for line_num, line in enumerate(lines, start=1):
                    # Ищем совпадения в конкретной строке
                    # finditer возвращает итератор с объектами Match
                    found_items = regex.finditer(line)
                    
                    for match in found_items:
                        match_str = match.group()
                        
                        # Дополнительная проверка: убедимся, что там обычный пробел (код 32),
                        # а не неразрывный (код 160 / \u00A0).
                        # Хотя наш regex явно ищет обычный пробел " ", перестраховка полезна.
                        if ' ' in match_str and '\u00A0' not in match_str:
                            # Формируем результат: (строка с ошибкой, (стр, строка))
                            coords = (f"Стр. {page_num}", f"Строка {line_num}")
                            matches_found.append((match_str, coords))

    except Exception as e:
        print(f"Произошла ошибка при обработке файла: {e}")
        return False, []

    has_errors = len(matches_found) > 0
    return has_errors, matches_found

def main():
    """
    Задача 3: Реализовать программное обеспечение, принимающее на вход путь к pdf-файлу.
    """
    print("=== Проверка неразрывных пробелов в PDF ===")
    print("Программа ищет сочетания (рис. 1, от 5 и т.д.) с обычным пробелом.")
    
    file_path = input("Введите путь к файлу (например, document.pdf): ").strip()
    
    # Убираем кавычки, если пользователь скопировал путь с ними
    file_path = file_path.replace('"', '').replace("'", "")
    
    is_found, results = check_pdf_spaces(file_path)
    
    print("\n--- Результаты анализа ---")
    if is_found:
        print(f"ВНИМАНИЕ: Найдено {len(results)} потенциальных ошибок (обычный пробел вместо неразрывного).\n")
        print(f"{'Найденный фрагмент':<25} | {'Координаты'}")
        print("-" * 50)
        
        for text, coords in results:
            coord_str = f"{coords[0]}, {coords[1]}"
            print(f"'{text}':<23} | {coord_str}")
            
        print("\nРекомендация: Замените обычные пробелы в этих местах на неразрывные (Ctrl+Shift+Space в Word).")
    else:
        # Если список пуст, значит "плохих" сочетаний нет (либо файл пуст/не читается)
        print("Ошибок не найдено. Либо в документе уже используются неразрывные пробелы, "
              "либо искомые сочетания отсутствуют.")

if __name__ == "__main__":
    main()
```

### Как это работает:

1.  **Regex (`get_regex_pattern`)**:
    *   `r"(?i)\b(рисунок|рис\.) \d+"`: Ищет слово "рисунок" или "рис." (независимо от регистра `(?i)`), за которым обязательно следует **обычный пробел** (в регулярном выражении пробел — это символ пробела), а затем цифры.
    *   Если в тексте будет стоять неразрывный пробел (`\u00A0`), это регулярное выражение **не сработает**, что нам и нужно (так как это правильная ситуация).
    *   Мы ищем именно *ошибки* (обычные пробелы).

2.  **Поиск (`check_pdf_spaces`)**:
    *   Открывает PDF.
    *   `extract_text()` получает содержимое страницы.
    *   `text.split('\n')` разбивает текст на визуальные строки (насколько это удалось распознать PyPDF2).
    *   Если найдено совпадение, оно добавляется в список с координатами (номер страницы, номер строки массива `lines`).

3.  **Интерфейс (`main`)**:
    *   Запрашивает путь.
    *   Выводит красивую таблицу с результатами или сообщение об успехе.
