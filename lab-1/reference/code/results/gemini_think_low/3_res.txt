### Анализ задачи и алгоритм решения

1.  **Инструментарий**: Используем библиотеку `PyPDF2` для чтения PDF. *Обратите внимание: PyPDF2 извлекает текст, но понятие "номер строки" в PDF довольно условно, так как PDF хранит текст блоками, а не строками. Мы будем разбивать извлеченный текст страницы по символу новой строки `\n`.*
2.  **Регулярное выражение (Вариант)**: Нам нужно найти места, где **ОТСУТСТВУЕТ** неразрывный пробел (NBSP, код `\u00A0`), но присутствует обычный пробел в сочетаниях типа "рисунок 1", "таблица 2", "менее 5".
    *   То есть мы ищем *ошибку*: обычный пробел там, где должен быть неразрывный.
    *   Примеры паттернов: `слово + обычный пробел + цифра`.
    *   Ключевые слова: "рисунок", "рис.", "таблица", "табл.", "от", "до", "менее", "свыше", "более".
    *   Регулярное выражение будет искать эти слова, за которыми следует *обычный* пробел (или несколько), а затем цифра.

### 1. Разработка регулярного выражения

Нам нужно ловить случаи с **обычным** пробелом (`\x20` или просто пробел), игнорируя случаи, где уже стоит неразрывный (`\u00A0`).

Регулярное выражение может выглядеть так:
`(?i)\b(рисунок|рис\.|таблица|табл\.|от|до|менее|свыше|более)[ ]+(\d+)`

*   `(?i)` — флаг игнорирования регистра (чтобы ловить и "Рисунок", и "рисунок").
*   `\b` — граница слова (чтобы не ловить внутри других слов).
*   `(рисунок|...|более)` — группа возможных вводных слов.
*   `[ ]+` — один или более **обычных** пробелов. Мы намеренно не используем `\s`, так как `\s` может включать и неразрывный пробел (в зависимости от настроек движка), и переносы строк. Нам нужен именно "плохой" пробел.
*   `(\d+)` — одно или более чисел.

```python
import re
import PyPDF2
import os

def check_missing_nbsp(pdf_path: str) -> tuple:
    """
    Функция для поиска отсутствия неразрывных пробелов в специальных сочетаниях
    слов и чисел в PDF-файле.

    :param pdf_path: Путь к файлу PDF.
    :return: Кортеж (found_issues: bool, results: list)
             - found_issues: Истина, если найдены "плохие" пробелы (ошибки).
             - results: Список кортежей (найденная_строка, (номер_страницы, номер_строки)).
    """
    
    # 1. Разработка регулярного выражения
    # Ищем: (Ключевые слова) + (Обычный пробел) + (Цифра)
    # Используем [ \t] для обозначения обычных пробелов и табуляции, исключая \u00A0
    regex_pattern = r'(?i)\b(рисунок|рис\.|таблица|табл\.|от|до|менее|свыше|более)[ \t]+(\d+)'
    compiled_regex = re.compile(regex_pattern)

    matches_list = []

    try:
        # Открываем PDF файл
        with open(pdf_path, 'rb') as file:
            reader = PyPDF2.PdfReader(file)
            
            # Проходим по всем страницам
            for page_num, page in enumerate(reader.pages):
                text = page.extract_text()
                
                if not text:
                    continue

                # Разбиваем текст страницы на строки для определения "номера строки"
                lines = text.split('\n')
                
                for line_idx, line in enumerate(lines):
                    # Ищем совпадения в конкретной строке
                    # finditer находит все вхождения в строке
                    for match in compiled_regex.finditer(line):
                        found_string = match.group(0)
                        
                        # Координаты: (Номер страницы + 1, Номер строки + 1)
                        # Добавляем +1 для человекочитаемого вида (с 1, а не с 0)
                        coordinates = (page_num + 1, line_idx + 1)
                        
                        matches_list.append((found_string, coordinates))

    except FileNotFoundError:
        print(f"Ошибка: Файл по пути '{pdf_path}' не найден.")
        return False, []
    except Exception as e:
        print(f"Произошла ошибка при обработке файла: {e}")
        return False, []

    # Формируем результат согласно заданию
    # Если список не пустой -> Истина (ошибки есть), иначе Ложь
    has_issues = len(matches_list) > 0
    
    return has_issues, matches_list

def main():
    """
    Основная функция программного обеспечения.
    Принимает путь к файлу и выводит результаты.
    """
    print("--- Проверка PDF на отсутствие неразрывных пробелов ---")
    file_path = input("Введите путь к PDF-файлу (например, document.pdf): ").strip()
    
    # Убираем кавычки, если пользователь скопировал путь с ними
    file_path = file_path.replace('"', '').replace("'", "")

    if not os.path.isfile(file_path):
        print("Указанный путь не является файлом.")
        return

    # Вызов функции поиска
    is_bad_formatting_found, details = check_missing_nbsp(file_path)

    print("\n--- Результаты анализа ---")
    if is_bad_formatting_found:
        print(f"Статус: ИСТИНА (Найдены места с отсутствием неразрывного пробела).")
        print(f"Всего найдено вхождений: {len(details)}")
        print("-" * 50)
        print(f"{'Стр.':<5} | {'Стр.док.':<10} | {'Найденный фрагмент'}")
        print("-" * 50)
        
        for text_fragment, coords in details:
            page_n, line_n = coords
            # Визуализируем проблему: заменим обычный пробел на подчеркивание для наглядности в выводе
            # (необязательно, но полезно для пользователя)
            display_fragment = text_fragment.replace(' ', '[PROBEL]')
            print(f"{page_n:<5} | {line_n:<10} | {text_fragment}")
            
    else:
        print("Статус: ЛОЖЬ (Ошибок форматирования согласно заданным критериям не найдено).")
        print("Список найденных элементов пуст.")

if __name__ == "__main__":
    main()
```

### Пояснения к коду

1.  **Regex (`r'(?i)\b(...)[ \t]+(\d+)'`)**:
    *   Это выражение ищет именно **ошибки**. Если в тексте написано `Рисунок\u00A01` (с правильным неразрывным пробелом), регулярное выражение его проигнорирует, так как `[ \t]` не совпадет с `\u00A0`.
    *   Если в тексте написано `Рисунок 1` (с обычным пробелом), регулярное выражение сработает, и программа сообщит об этом как о потенциальном месте разрыва строки.

2.  **`page.extract_text()`**:
    *   Этот метод извлекает текст со страницы. Качество извлечения зависит от самого PDF. Если PDF создан как картинка (скан), текст не извлечется (нужен OCR, но это выходит за рамки задания PyPDF2).

3.  **Нумерация строк**:
    *   PDF — это формат верстки, а не текстовый редактор. Понятие "строка 5" там отсутствует, есть координаты `x,y` для каждой буквы. `PyPDF2` пытается собрать текст в линии, разделяя их `\n`. Мы используем индекс этого списка `lines` как номер строки.
