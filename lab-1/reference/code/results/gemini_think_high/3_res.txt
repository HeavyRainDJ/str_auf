Вот готовое решение на языке Python, использующее библиотеку `PyPDF2` (версии 3.0.0+) и модуль регулярных выражений `re`.

### Описание решения

1.  **Регулярное выражение**: Задача состоит в поиске **отсутствия** неразрывного пробела. Это значит, что мы ищем места, где стоит **обычный пробел** (ASCII 32) между ключевым словом и числом. Если мы находим такое совпадение — это ошибка верстки.
2.  **Функция**: Открывает PDF, извлекает текст постранично, разбивает его на строки (по символу `\n`) и проверяет каждую строку регулярным выражением.
3.  **Координаты**: В `PyPDF2` нет понятия "строка" как в текстовом редакторе, но метод `extract_text()` возвращает текст, где визуальные строки обычно разделены переносом `\n`. Мы используем порядковый номер элемента в списке после `split('\n')` как номер строки.

### Код программы

```python
import re
import os
import PyPDF2

def get_suspicious_spaces_regex():
    """
    Задача 1: Разработать регулярные выражения.
    
    Мы ищем комбинации, где между словом и числом стоит ОБЫЧНЫЙ пробел (или табуляция),
    вместо неразрывного (\xa0).
    
    Ключевые слова: рисунок, таблица, рис, табл, от, до, менее, свыше.
    (?i) - флаг игнорирования регистра.
    \b - граница слова (чтобы не искать внутри других слов).
    [ \t]+ - один или более обычных пробелов или табуляций (исключает \xa0).
    \d+ - одно или более чисел.
    """
    return re.compile(r'(?i)\b(?:рисунок|таблица|рис\.|табл\.|от|до|менее|более|свыше)[ \t]+\d+')

def search_text_in_pdf(file_path):
    """
    Задача 2: Реализовать функцию для поиска подстроки.
    
    Аргументы:
        file_path (str): Путь к файлу PDF.
        
    Возвращает:
        tuple: (bool, list)
            - bool: True, если найдены вхождения (ошибки), иначе False.
            - list: Список кортежей вида (найденная_строка, (номер_страницы, номер_строки)).
    """
    regex = get_suspicious_spaces_regex()
    found_entries = []
    
    if not os.path.exists(file_path):
        print(f"Ошибка: Файл '{file_path}' не найден.")
        return False, []

    try:
        # Открываем PDF файл
        with open(file_path, 'rb') as pdf_file:
            reader = PyPDF2.PdfReader(pdf_file)
            
            # Проходим по всем страницам
            for page_number, page in enumerate(reader.pages, start=1):
                text = page.extract_text()
                
                if not text:
                    continue
                
                # Разбиваем текст страницы на строки по символу переноса
                lines = text.split('\n')
                
                for line_number, line_content in enumerate(lines, start=1):
                    # Ищем совпадения в текущей строке
                    matches = regex.findall(line_content)
                    
                    for match in matches:
                        # Дополнительная проверка: убедимся, что там действительно нет NBSP
                        # (хотя регулярное выражение [ \t] уже это подразумевает)
                        if '\xa0' not in match:
                            # Сохраняем результат: (сама фраза, (страница, строка))
                            found_entries.append((match, (page_number, line_number)))
                            
    except Exception as e:
        print(f"Произошла ошибка при обработке файла: {e}")
        return False, []

    # Возвращаем кортеж согласно заданию: (истина/ложь, список)
    has_matches = len(found_entries) > 0
    return has_matches, found_entries

def main():
    """
    Задача 3: Реализовать ПО, принимающее на вход путь к файлу.
    """
    print("=== Проверка PDF на отсутствие неразрывных пробелов ===")
    print("Поиск ошибок в сочетаниях типа: 'рисунок 1', 'таблица 2', 'от 1 до 5' и т.д.")
    
    file_path = input("Введите путь к PDF-файлу: ").strip()
    
    # Удаляем кавычки, если пользователь скопировал путь с ними
    if file_path.startswith('"') and file_path.endswith('"'):
        file_path = file_path[1:-1]

    is_found, results = search_text_in_pdf(file_path)

    print("\n--- Результаты анализа ---")
    if is_found:
        print(f"Статус: ИСТИНА (Найдены потенциальные ошибки: {len(results)} шт.)")
        print(f"{'Фраза':<30} | {'Стр.':<5} | {'Стр. в док.':<5}")
        print("-" * 50)
        
        for text, coords in results:
            page_num, line_num = coords
            print(f"'{text}':{' ':<25} | {page_num:<5} | {line_num:<5}")
            
        print("\nСовет: В найденных местах рекомендуется заменить обычный пробел на неразрывный (Ctrl+Shift+Space в Word).")
    else:
        print("Статус: ЛОЖЬ (Ошибок с обычными пробелами в указанных сочетаниях не найдено).")

if __name__ == "__main__":
    main()
```

### Пояснения к выполнению задания

1.  **Задача 1 (Regex)**:
    Используется паттерн `r'(?i)\b(?:рисунок|...)[ \t]+\d+'`.
    *   `(?i)` — делает поиск нечувствительным к регистру (найдет и "Рисунок 1", и "рисунок 1").
    *   `\b` — граница слова, чтобы не находить совпадения внутри слов (например, "подо**с** 5", если бы "с" было ключевым словом, но здесь это просто мера предосторожности).
    *   `(?:...)` — группировка ключевых слов.
    *   `[ \t]+` — **самая важная часть**. Мы ищем именно *обычные* пробелы или табуляцию. Мы намеренно не используем `\s`, так как `\s` в Python Regex может включать в себя `\xa0` (неразрывный пробел), а нам нужно найти именно его отсутствие (ошибку).

2.  **Задача 2 (Функция)**:
    Функция `search_text_in_pdf` возвращает требуемую структуру данных. Координаты определяются как `(Номер страницы PDF, Номер строки текста на этой странице)`.
    *Примечание:* Номера строк являются приблизительными и зависят от того, как `PyPDF2` извлек текстовый слой.

3.  **Задача 3 (Интерфейс)**:
    Простая консольная оболочка, запрашивающая путь и выводящая таблицу с результатами.
