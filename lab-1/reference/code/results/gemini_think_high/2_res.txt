Вот решение вашей задачи. Код написан на Python с использованием библиотеки `PyPDF2` и модуля `re`.

### Описание решения

1.  **Регулярные выражения**:
    Мы ищем ситуацию, когда между ключевым словом (например, "рисунок", "таблица") и числом стоит **обычный пробел** (код 32) или табуляция, вместо **неразрывного пробела** (`\u00A0`).
    Паттерн: `(?i)\b(ключевые_слова)[ \t]+(\d+)`
    *   `(?i)` — игнорирование регистра (найдет и "Рисунок", и "рисунок").
    *   `\b` — граница слова.
    *   `[ \t]+` — один или более обычных пробелов (именно их мы считаем ошибкой верстки в данном контексте).
    *   `\d+` — число.

2.  **Определение координат**:
    PDF — это не текстовый файл, в нем нет понятия "строк" в привычном смысле. Метод `extract_text()` возвращает текст страницы. Мы разбиваем этот текст по символу переноса строки (`\n`), чтобы симулировать нумерацию строк для отчета.

### Программный код

Сохраните этот код в файл, например `pdf_checker.py`.

```python
import re
import os
import PyPDF2

def get_regex_pattern():
    """
    1. Разработка регулярного выражения по варианту.
    Задача: Найти обычные пробелы (вместо неразрывных) в сочетаниях:
    "рисунок 1", "таблица 2", "от 1 до 5", "менее 5", "свыше 25".
    """
    # Список ключевых слов (корни слов), после которых часто идет число
    keywords = [
        r"рисун[а-я]*",  # рисунок, рисунка, рисунку и т.д.
        r"рис\.",        # сокращение рис.
        r"таблиц[а-я]*", # таблица, таблицы и т.д.
        r"табл\.",       # сокращение табл.
        r"от",
        r"до",
        r"менее",
        r"более",
        r"свыше"
    ]
    
    # Объединяем ключевые слова через ИЛИ (|)
    keywords_group = "|".join(keywords)
    
    # Итоговое регулярное выражение:
    # (?i) - флаг игнорирования регистра
    # \b - граница слова (начало)
    # (...) - группа ключевых слов
    # [ \t]+ - ОБЫЧНЫЙ пробел или таб (один или более). Если там стоит \xA0 (NBSP), совпадения не будет.
    # \d+ - одна или более цифр
    pattern_str = fr'(?i)\b(?:{keywords_group})[ \t]+\d+'
    
    return re.compile(pattern_str)

def find_missing_nbsp(pdf_path):
    """
    2. Функция для поиска подстроки по варианту в pdf-файле.
    Возвращает кортеж:
    - (bool) Найдено ли хоть одно вхождение (истина/ложь).
    - (list) Список кортежей: (найденная_строка, (номер_страницы, номер_строки)).
    """
    results = []
    regex = get_regex_pattern()
    found_any = False

    try:
        # Открываем PDF файл
        with open(pdf_path, 'rb') as file:
            reader = PyPDF2.PdfReader(file)
            
            # Проходим по всем страницам
            for page_num, page in enumerate(reader.pages):
                # Извлекаем текст со страницы
                text = page.extract_text()
                
                if not text:
                    continue
                
                # Разбиваем текст на строки для определения "координат" (номер строки)
                lines = text.split('\n')
                
                for line_idx, line in enumerate(lines):
                    # Ищем совпадения в конкретной строке
                    matches = regex.finditer(line)
                    
                    for match in matches:
                        found_string = match.group(0)
                        # Координаты: (Номер страницы (с 1), Номер строки (с 1))
                        coordinates = (page_num + 1, line_idx + 1)
                        results.append((found_string, coordinates))
                        found_any = True

    except FileNotFoundError:
        print(f"Ошибка: Файл по пути '{pdf_path}' не найден.")
        return False, []
    except Exception as e:
        print(f"Произошла ошибка при чтении PDF: {e}")
        return False, []

    return found_any, results

def main():
    """
    3. Реализация программного обеспечения, принимающего на вход путь к pdf-файлу.
    """
    print("--- Проверка отсутствия неразрывного пробела в PDF ---")
    print("Программа ищет сочетания (Рис. 1, Таблица 5, от 1 и т.д.), где стоит обычный пробел.")
    
    pdf_path = input("Введите путь к файлу (например, document.pdf): ").strip()
    
    # Убираем кавычки, если пользователь скопировал путь как "C:\Path\..."
    if pdf_path.startswith('"') and pdf_path.endswith('"'):
        pdf_path = pdf_path[1:-1]

    if not os.path.exists(pdf_path):
        print("Файл не существует. Проверьте путь.")
        return

    # Вызов функции поиска
    is_found, matches = find_missing_nbsp(pdf_path)

    if is_found:
        print(f"\n[РЕЗУЛЬТАТ] ИСТИНА: Найдены потенциальные ошибки ({len(matches)} шт.)")
        print(f"{'Стр.':<5} | {'Стр.док.':<8} | {'Найденный фрагмент'}")
        print("-" * 40)
        for text, coords in matches:
            page_n, line_n = coords
            print(f"{page_n:<5} | {line_n:<8} | '{text}'")
    else:
        print("\n[РЕЗУЛЬТАТ] ЛОЖЬ: Ошибочных сочетаний с обычным пробелом не найдено.")
        print("(Либо таких сочетаний нет, либо везде используются неразрывные пробелы).")

if __name__ == "__main__":
    main()
```

### Пояснения к реализации

*   **Библиотека**: Использован класс `PdfReader` (актуален для `PyPDF2` версии 3.0+). Если у вас очень старая версия библиотеки, возможно, потребуется использовать `PdfFileReader`.
*   **Логика регулярного выражения**: Задание требует проверить **отсутствие** неразрывного пробела там, где он должен быть. Это значит, что программа ищет "плохие" случаи — когда между словом (например, "рис.") и числом стоит обычный пробел. Если программа ничего не находит (возвращает "ложь"), значит документ сверстан правильно (или таких слов нет).
*   **Координаты**: `PyPDF2` извлекает текст сплошным потоком или блоками. Номер строки определяется путем разбиения извлеченного текста страницы по символам новой строки (`\n`). Это приблизительная оценка визуальной строки, достаточная для выполнения учебного задания.
