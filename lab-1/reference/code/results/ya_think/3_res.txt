Наконец, я создам программное обеспечение, которое принимает на вход путь к PDF-файлу и использует разработанную функцию.

Регулярное выражение должно учитывать шаблоны для «рисунок X», «таблица X», «от X до Y», «менее X», «свыше X», где X и Y — числа. Для проверки неразрывного пробела я буду искать обычные пробелы и проверять, соответствуют ли они ожидаемым шаблонам.

Функция будет читать PDF-файл, извлекать текст с каждой страницы, применять регулярное выражение и сохранять найденные строки вместе с номером страницы и строки.</blockquote>

**Вот пример кода для решения поставленной задачи:**

```python
import re
import PyPDF2

# Регулярное выражение для поиска сочетаний «рисунок X», «таблица X», «от X до Y», «менее X», «свыше X»
# Здесь X и Y — цифры. Проверяем, что между словами и цифрами есть обычный пробел (\s), а не неразрывный (\u00A0)
pattern = re.compile(
    r'(?:рисунок|таблица)\s\d+|'  # рисунок 1, таблица 2 и т. д.
    r'от\s\d+\sдо\s\d+|'         # от 1 до 5 и т. д.
    r'(?:менее|свыше)\s\d+'      # менее 5, свыше 25 и т. д.
)

def find_substrings(pdf_path):
    with open(pdf_path, 'rb') as file:
        reader = PyPDF2.PdfReader(file)
        result = []
        for page_num, page in enumerate(reader.pages, start=1):
            text = page.extract_text()
            if text:
                lines = text.split('\n')
                for line_num, line in enumerate(lines, start=1):
                    matches = pattern.finditer(line)
                    for match in matches:
                        result.append((match.group(), (page_num, line_num)))
        return (len(result) > 0, result)

def main(pdf_path):
    exists, found_items = find_substrings(pdf_path)
    if exists:
        print("Найденные сочетания:")
        for item, coords in found_items:
            print(f"Строка: {item}, координаты: страница {coords[0]}, строка {coords[1]}")
    else:
        print("Сочетаний не найдено.")

# Пример использования
pdf_file_path = 'путь_к_вашему_файлу.pdf'
main(pdf_file_path)
```

**Объяснение кода:**

1. **Импортируем необходимые библиотеки:** `re` для работы с регулярными выражениями и `PyPDF2` для работы с PDF-файлами.

2. **Создаём регулярное выражение `pattern`,** которое ищет следующие шаблоны:
* «рисунок X» или «таблица X»;
* «от X до Y»;
* «менее X» или «свыше X».
Здесь X и Y — цифры, а между словами и цифрами должен быть обычный пробел.

3. **Функция `find_substrings`:**
* открывает PDF-файл;
* перебирает все страницы;
* извлекает текст с каждой страницы;
* разбивает текст на строки;
* ищет совпадения с регулярным выражением на каждой строке;
* сохраняет найденные строки и их координаты (номер страницы и строки).

4. **Функция `main`:**
* вызывает `find_substrings`;
* выводит результаты поиска.

5. **В конце задаём путь к PDF-файлу и вызываем функцию `main`.**

**Обратите внимание:**
* Для корректной работы кода убедитесь, что у вас установлена библиотека `PyPDF2`. Установить её можно с помощью команды `pip install PyPDF2`.
* Эффективность извлечения текста из PDF может зависеть от качества исходного файла. В некоторых случаях `PyPDF2` может некорректно извлекать текст.
* Регулярное выражение в примере ищет только указанные шаблоны. Если вам нужно расширить поиск, модифицируйте выражение соответственно.
