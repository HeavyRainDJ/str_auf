**Вот пример реализации программного обеспечения на Python для решения поставленной задачи:**

```python
import re
import PyPDF2

# Регулярное выражение для поиска сочетаний «рисунок X», «таблица X», «от X до Y», «менее X», «свыше X»
# где X и Y — числа. Проверяет наличие неразрывного пробела (\u00A0)
pattern = re.compile(
    r'(?:рисунок|таблица)\s*(\u00A0| )\d+|'  # рисунок/таблица с числом
    r'от\s*(\u00A0| )\d+\s*(\u00A0| )до\s*(\u00A0| )\d+|'  # от X до Y
    r'(?:менее|свыше)\s*(\u00A0| )\d+',  # менее/свыше X
    re.IGNORECASE
)

def find_non_breaking_spaces(pdf_path):
    with open(pdf_path, 'rb') as file:
        reader = PyPDF2.PdfReader(file)
        result = []
        has_non_breaking_space = False

        for page_num, page in enumerate(reader.pages, start=1):
            text = page.extract_text()
            if not text:
                continue

            lines = text.split('\n')
            for line_num, line in enumerate(lines, start=1):
                matches = pattern.finditer(line)
                for match in matches:
                    if '\u00A0' in match.group():
                        has_non_breaking_space = True
                        result.append((match.group(), (page_num, line_num)))

        return has_non_breaking_space, result

def main(pdf_path):
    has_non_breaking_space, findings = find_non_breaking_spaces(pdf_path)
    if has_non_breaking_space:
        print("Найден неразрывный пробел в следующих строках:")
        for finding in findings:
            print(f"Строка: {finding[0]}, страница: {finding[1][0]}, строка документа: {finding[1][1]}")
    else:
        print("Неразрывные пробелы в специальных сочетаниях не найдены.")

# Пример использования
pdf_file_path = 'путь_к_вашему_файлу.pdf'
main(pdf_file_path)
```

**Объяснение работы программы:**

1. **Регулярное выражение:** шаблон `pattern` ищет сочетания «рисунок X», «таблица X», «от X до Y», «менее X», «свыше X», где X и Y — числа. Он проверяет наличие неразрывного пробела (`\u00A0`) между словами и числами.

2. **Функция `find_non_breaking_spaces`:**
* открывает PDF-файл и читает его с помощью `PyPDF2.PdfReader`;
* перебирает все страницы и извлекает текст;
* разбивает текст на строки и ищет совпадения с регулярным выражением;
* если находит неразрывный пробел, устанавливает флаг `has_non_breaking_space` в `True` и добавляет найденную строку и её координаты в список `result`.

3. **Функция `main`:**
* вызывает `find_non_breaking_spaces`;
* выводит результаты: если найдены неразрывные пробелы, выводит строки, где они обнаружены, вместе с номером страницы и строки документа. Если неразрывных пробелов нет, сообщает об этом.
