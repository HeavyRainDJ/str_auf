**Пример реализации:**

```python
import re
import PyPDF2

# Регулярные выражения для поиска сочетаний
patterns = [
    r'рисунок\s+\d+',
    r'таблица\s+\d+',
    r'от\s+\d+\s+до\s+\d+',
    r'менее\s+\d+',
    r'свыше\s+\d+'
]

def find_substrings(pdf_path):
    # Открытие PDF-файла
    with open(pdf_path, 'rb') as file:
        reader = PyPDF2.PdfReader(file)
        result = []
        found = False

        # Перебор страниц
        for page_num, page in enumerate(reader.pages):
            text = page.extract_text()
            if text:
                lines = text.split('\n')
                for line_num, line in enumerate(lines):
                    for pattern in patterns:
                        matches = re.finditer(pattern, line)
                        for match in matches:
                            found = True
                            result.append((match.group(), (page_num + 1, line_num + 1)))
        return found, result

def main(pdf_path):
    found, matches = find_substrings(pdf_path)
    if found:
        print("Найденные сочетания:")
        for match, coords in matches:
            print(f"Сочетание: {match}, страница: {coords[0]}, строка: {coords[1]}")
    else:
        print("Сочетания не найдены.")

# Пример использования
pdf_path = 'путь_к_вашему_файлу.pdf'
main(pdf_path)
```

**Пояснения к коду:**

- **Импортируются библиотеки:** `re` для работы с регулярными выражениями и `PyPDF2` для работы с PDF-файлами.
- **Определяются регулярные выражения** для поиска сочетаний «рисунок X», «таблица X», «от X до Y», «менее X», «свыше X».
- **Функция `find_substrings`:**
  - Открывает PDF-файл и читает его страницы.
  - Для каждой страницы извлекает текст и разбивает его на строки.
  - Проверяет каждую строку на соответствие регулярным выражениям.
  - Если находит совпадения, добавляет их в список `result` вместе с координатами (номер страницы и номер строки).
- **Функция `main`:**
  - Вызывает `find_substrings` и выводит результаты.

**Важно:**
- Убедитесь, что библиотека `PyPDF2` установлена. Её можно установить с помощью `pip install PyPDF2`.
- Путь к PDF-файлу (`pdf_path`) нужно указать перед запуском программы.
- Код предполагает, что текст в PDF-файле корректно извлекается методом `extract_text()`. В некоторых случаях извлечение текста может быть затруднено из-за особенностей документа.
