```python
import re
import PyPDF2

# Регулярное выражение для поиска сочетаний «рисунок 1», «таблица 2», «от 1 до 5», «менее 5», «свыше 25» и т. д.
# Предполагается, что числа могут быть от 0 до 999, но регулярное выражение можно расширить при необходимости
pattern = re.compile(
    r'\b(рисунок|таблица|от\s+\d+\s+до\s+\d+|менее\s+\d+|свыше\s+\d+)\b',
    re.IGNORECASE
)

def find_substrings_in_pdf(pdf_path):
    found_items = []
    page_number = 0

    with open(pdf_path, 'rb') as file:
        reader = PyPDF2.PdfReader(file)
        for page in reader.pages:
            page_number += 1
            text = page.extract_text()
            if text:
                line_number = 0
                for line in text.split('\n'):
                    line_number += 1
                    matches = pattern.finditer(line)
                    for match in matches:
                        found_items.append((match.group(), (page_number, line_number)))

    if found_items:
        return True, found_items
    else:
        return False, []

def main(pdf_path):
    result, items = find_substrings_in_pdf(pdf_path)
    if result:
        print("Найденные сочетания:")
        for item, coords in items:
            print(f"Сочетание: {item}, страница: {coords[0]}, строка: {coords[1]}")
    else:
        print("Сочетания не найдены.")

# Пример использования
pdf_file_path = 'путь_к_вашему_файлу.pdf'
main(pdf_file_path)
```

**Объяснение кода:**

1. **Импортируются необходимые библиотеки:** `re` для работы с регулярными выражениями и `PyPDF2` для работы с PDF-файлами.

2. **Создаётся регулярное выражение** для поиска нужных сочетаний слов и чисел. В данном случае ищутся сочетания «рисунок», «таблица», «от X до Y», «менее X», «свыше X».

3. **Функция `find_substrings_in_pdf`:**
* открывает PDF-файл;
* проходит по каждой странице;
* извлекает текст;
* ищет совпадения с регулярным выражением;
* сохраняет найденные сочетания и их координаты (номер страницы и строки).

4. **Функция `main`:**
* вызывает `find_substrings_in_pdf`;
* выводит результаты поиска.

5. **В конце приводится пример использования программы**, где нужно указать путь к PDF-файлу.

**Обратите внимание:**
* Для корректной работы кода убедитесь, что библиотека `PyPDF2` установлена. Установить её можно с помощью команды `pip install PyPDF2`.
* В зависимости от структуры PDF-файла, извлечение текста может быть неточным. Некоторые PDF-файлы могут содержать форматирование, которое затрудняет извлечение текста.
* Регулярное выражение в примере покрывает базовые случаи. Его можно модифицировать для учёта дополнительных вариантов сочетаний.
