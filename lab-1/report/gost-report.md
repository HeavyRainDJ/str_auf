## Как воспроизвести проверку

```powershell
$env:PYTHONUTF8='1'; $env:PYTHONIOENCODING='utf-8'   # иначе poppler-вывод читается как cp1251
python .dsh\skills\gost-7-32-latex\scripts\gost_check.py `
    "Лаб-1\report\report.tex" `
    --pdf "Лаб-1\report\report.pdf" --doc-type vkr `
    --json gost-report.json --md gost-report.md
```
