# Архив версий и промтов

Проверено наличие файлов в архивах моделей.

| Модель | Версии | Состояние архива |
|---|---:|---|
| GigaChat | 01–04 | Все версии содержат `prompt.txt`, `response.md`, `solution.py`; в v01 также сохранены лог и requirements. |
| Qwen | 01–03 | Все версии содержат `prompt.txt`, `response.md`, `solution.py`; дополнительные файлы сохранены в исходных версиях. |
| Алиса | 01–03 | v02–v03 содержат промт, ответ и код. v01 содержит `prompt.txt` и `status.txt`: режим эксперта вернул пустой ответ, поэтому кода и `response.md` для этой версии не существует. |
| Ассистент МГТУ (Королёв) | 01–03 | Все версии содержат промты, ответы и код; для всех сохранены `adapter.json`. |
| DeepSeek | 01–03 | Все версии содержат код, ответы, промты и `adapter.json`; подробная история — `deepseek/HISTORY.md`. |

Проверка выполнена по фактическому содержимому каталогов `models/*/*`, без создания отсутствующих ответов задним числом.
