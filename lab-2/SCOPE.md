# Итоговый объём лабораторной работы № 2

Для каждой из трёх моделей создаются две блок-схемы по ГОСТ 19.701-90:

1. Python в draw.io XML — `python_gost.drawio`;
2. C++ в yEd GraphML — `cpp_gost.graphml`.

Всего в итоговом сравнении участвуют шесть диаграмм.

Общий промпт: `prompts/final_prompt_all_models.txt`.

Проверка выполняется в два этапа: автоматический анализ XML и ручное открытие в соответствующем графическом редакторе.
