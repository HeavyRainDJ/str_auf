# Сведения для итогового LaTeX-отчёта

## Постановка эксперимента

- Исследуются три модели: Qwen, Korolev AI и DeepSeek.
- Всем моделям передаётся один и тот же стандартизированный промпт `prompts/final_prompt_all_models.txt`.
- Каждая модель должна создать ровно две диаграммы по ГОСТ 19.701-90:
  - `python_gost.drawio` — блок-схема реализации Python в draw.io XML;
  - `cpp_gost.graphml` — блок-схема реализации C++ в yEd GraphML.
- Итоговый объём: две диаграммы на модель, всего шесть диаграмм.
- Каждый фактически полученный ответ модели учитывается отдельно. Если модель делит два файла на несколько сообщений, каждое сообщение считается отдельным ответом ИИ.
- Исходные ответы сохраняются без изменений в `iterations/NN/raw`, извлечённые файлы — в `iterations/NN/artifacts`, результаты проверки — в `iterations/NN/verification`.
- Исправляющий промпт создаётся только для выявленного дефекта одного из двух обязательных файлов.
