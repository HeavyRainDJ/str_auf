# DeepSeek

Итоговая постановка требует два файла: `python_gost.drawio` и `cpp_gost.graphml`.

Единый промпт для отправки: `prompts/prompt_to_send.txt`.

Новые ответы сохраняются по порядку в `iterations/NN`, проверенные файлы — в `final`. Если модель разделяет выдачу на несколько сообщений, каждое сообщение учитывается как отдельный ответ ИИ.

## Текущее состояние

- `python_gost.drawio` из итерации `04` принят и зафиксирован в `final/python_gost.drawio` как окончательный вариант.
- `cpp_gost.graphml` из итерации `06` принят и зафиксирован в `final/cpp_gost.graphml` как окончательный вариант.
- Работа над обоими файлами завершена; последующие изменения выполняются только по отдельному новому запросу.
