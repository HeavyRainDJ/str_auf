## Главная ошибка

В yEd текст визуально расположен не в геометрическом центре фигур: у параллелограммов и ромбов подписи прижаты к верхней части, а у ряда остальных узлов центр текста также не совпадает с центром фигуры.

Одних атрибутов `modelPosition="c"` и `autoSizePolicy="node_size"` оказалось недостаточно. Не используй `autoSizePolicy="node_size"` в новой версии.

## Как исправить подписи узлов

Для КАЖДОГО `y:NodeLabel` задай явный прямоугольник подписи и расположи этот прямоугольник точно по центру соответствующего `y:Geometry`.

1. Используй `autoSizePolicy="none"`, `alignment="center"`, `horizontalTextPosition="center"`, `verticalTextPosition="center"`, `modelName="internal"`, `modelPosition="c"`.
2. У каждого `y:NodeLabel` обязательно должны присутствовать числовые атрибуты `x`, `y`, `width` и `height`.
3. Координаты `x` и `y` подписи задаются относительно узла. Рассчитывай их так:
   - `x = (ширина узла - ширина подписи) / 2`;
   - `y = (высота узла - высота подписи) / 2`.
4. Высота прямоугольника подписи должна соответствовать реальной высоте текста, а не всей высоте фигуры:
   - одна строка — примерно `18`–`20` px;
   - две строки — примерно `34`–`40` px;
   - три строки — примерно `50`–`58` px;
   - четыре строки — примерно `66`–`76` px.
5. Ширину подписи выбирай меньше внутренней ширины фигуры. Для ромбов оставляй увеличенные боковые поля, чтобы текст не приближался к наклонным граням.
6. Длинный текст разбивай обычными переводами строк внутри `y:NodeLabel`. Строки должны быть визуально сбалансированы по длине.
7. Центр всего многострочного блока текста должен совпадать с центром фигуры. Не размещай первую строку на верхней границе или рядом с ней.
8. Сохрани `fontFamily="Dialog"`, `fontSize="12"`, `fontStyle="plain"`, `hasBackgroundColor="false"`, `hasLineColor="false"`, `textColor="#000000"`, `visible="true"`.

Пример для узла размером `260 × 60` с однострочной подписью размером `220 × 20`:

`x="20" y="20" width="220" height="20"`

Пример для ромба размером `260 × 110` с двухстрочной подписью размером `180 × 40`:

`x="40" y="35" width="180" height="40"`

Эти значения являются примером расчёта. Для каждого узла вычисли собственные значения по его размеру и количеству строк.

## Что сохранить без ухудшений

1. Не меняй смысл и порядок алгоритма, типы фигур, идентификаторы узлов и рёбер.
2. Сохрани существующие координаты и размеры фигур, если текст после правильного центрирования помещается внутри них.
3. Сохрани у каждого ребра `<y:Arrows source="none" target="standard"/>` — наконечники сейчас обязательны.
4. Сохрани ортогональную трассировку: только горизонтальные и вертикальные участки с поворотами на 90 градусов.
5. Не допускай прохождения линий через фигуры, текст и подписи `Да`/`Нет`.
6. У каждого ромба должно остаться ровно две исходящие подписанные ветви.

Перед выдачей проверь:

- возвращён только `cpp_gost.graphml`;
- XML синтаксически корректен;
- у каждого `y:NodeLabel` есть `autoSizePolicy="none"` и явные `x`, `y`, `width`, `height`;
- прямоугольник каждой подписи математически центрирован внутри своего узла;
- текст визуально находится в центре каждой фигуры;
- все рёбра сохранили `target="standard"` и ортогональные маршруты.
