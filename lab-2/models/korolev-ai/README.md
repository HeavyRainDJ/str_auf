# Korolev AI

Итоговая постановка требует два файла: `python_gost.drawio` и `cpp_gost.graphml`.

Исходный единый промпт сохранён в `prompts/prompt_to_send.txt` как часть протокола эксперимента. После фактического сбоя совмещённой генерации дальнейшая работа разделена на два независимых самодостаточных промпта для новых диалогов:

- `prompts/prompt_drawio_to_send.txt` — только `python_gost.drawio`, внутри полностью вложен исходный XML из итерации 08;
- `prompts/prompt_yed_to_send.txt` — только `cpp_gost.graphml` для yEd, внутри полностью вложен последний целый GraphML из итерации 07.

Идентичные архивные копии называются `prompt_drawio_new_chat.txt` и `prompt_yed_new_chat.txt`. Каждый файл можно отправлять первым сообщением в отдельный новый диалог: предыдущий контекст модели не требуется.

Новые результаты сохраняются по порядку в `iterations/NN`, проверенные файлы — в `final`. Начиная после итерации 08, запрос разделён на два последовательных сообщения — отдельно draw.io и отдельно yEd. Каждый промпт и полученный на него ответ считаются самостоятельной итерацией модели.

Текущий статус: эксперимент завершён после 15 учтённых итераций. Draw.io итерации 12 и GraphML итерации 15 приняты пользователем и сохранены в `final`.

Общая оценка эксперимента: Korolev AI показал низкую устойчивость при создании и последовательной коррекции крупных XML-диаграмм. Исправление одного дефекта часто сопровождалось появлением другого; модель нарушала явно заданные координаты и текст условий, обрывала длинный GraphML, а накопленный диалог завершился переполнением контекстного окна. Для получения двух принятых файлов потребовалось 15 учтённых итераций, разделение работы на новые диалоги и точное кодирование отдельных символов. Развёрнутая академическая оценка находится в `evaluation.md`.
