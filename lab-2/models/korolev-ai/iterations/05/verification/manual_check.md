# Ручная проверка итерации 05

Источник результата: проверка файлов пользователем в draw.io и yEd Graph Editor.

## yEd Graph Editor

Файл открывается, однако текст отображается не во всех элементах. Следовательно, успешный синтаксический разбор XML и структурная проверка GraphML не подтверждают корректное визуальное отображение схемы. Файл `cpp_gost.graphml` не принят как итоговый.

Для следующей версии требуется явно задать полные параметры `y:NodeLabel` и `y:EdgeLabel`, использовать текстовое содержимое элементов, фактические переводы строк, достаточную геометрию блоков и автоматический размер подписей.

## draw.io

В точках ветвления визуально непонятно, какая стрелка соответствует условию `Да`, а какая — `Нет`. Файл `python_gost.drawio` не принят как итоговый.

Для следующей версии требуется:

- разместить подписи `Да` и `Нет` около начала соответствующих стрелок;
- задать каждой подписи уникальный `id` и собственную геометрию;
- задать явные стороны выхода стрелок из ромбов;
- не размещать подписи на линии, наконечнике или границе ромба.

## Итог

После ручной проверки оба файла итерации 05 требуют исправления. Автоматический статус GraphML «готов к ручному открытию» не означает принятия итогового результата.
