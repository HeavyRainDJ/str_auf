# Лабораторная работа 2

Работа посвящена получению схем алгоритма с помощью больших языковых моделей и их импорту в draw.io и yEd Graph Editor.

Единый окончательный промпт для Qwen, Korolev AI и DeepSeek находится в файле `prompts/final_prompt_all_models.txt`. Во все три модели необходимо отправлять текст без изменений. Ответ каждой модели следует сохранять отдельно, чтобы в отчёте можно было сопоставить полноту, корректность и импортируемость результатов.
